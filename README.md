# SkillBridge

SkillBridge is a client-side hackathon prototype that helps displaced and refugee professionals turn demonstrated skills into local mentorship and fellowship opportunities—even when formal certificates, academic transcripts, or documents are missing.

## Prototype Disclaimer

- **SkillBridge is a prototype.** Match scores and practical assessments are illustrative only, not official credential verification, legal advice, or a promise of employment.
- All candidate profiles, sample organizations, fellowship opportunities, mentor profiles, and impact metrics in this app are **fictional demo data**.
- Nothing in this app collects refugee case numbers, exact home addresses, sensitive identity documents, or legal-status details.
- Candidates should always confirm employment and work-authorization requirements with qualified local support organizations.

## Running Locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Demo Workflow

1. Start on **Overview** with the prefilled demo candidate profile and live progress summary.
2. Open **My Skills Passport** to edit skills, location (city/county only), and project evidence, or complete the 3-question practice assessment.
3. Visit **Opportunities** to see updated, explainable skill-match percentages, filter listings, save opportunities, and record local demo interest.
4. Visit **Mentorship** to review safeguarding guidelines and submit a local demo mentorship request.
5. Use **Reset demo data** in the top navigation bar at any time to restore the initial seeded state stored in `localStorage`.
